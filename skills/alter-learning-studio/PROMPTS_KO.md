# Codex / Claude Code 활용 프롬프트

## 1. 처음 공부하기

```text
$alter-learning-studio
주제: HTTP와 HTTPS의 차이
내 수준: 백엔드 개발 경험은 있지만 TLS 핸드셰이크는 잘 모름
목표: 요청이 암호화되는 과정과 인증서 검증을 그림으로 설명하고 싶음
A.L.T.E.R. 방식으로 핵심 챕터를 구성하고 가장 중요한 개념을
오프라인 HTML 모션그래픽으로 만들어줘. 가정/실제 동작을 구분해줘.
```

## 2. 이전 학습 이어가기

```text
$alter-learning-studio
현재 저장소의 learning/PLAN.md 와 learning/PROGRESS.md를 읽어
마지막 완료 챕터 이후부터 이어서 학습시켜줘.
먼저 2개 문제로 이해도를 진단하고 다음 실습을 제시해줘.
```

## 3. 시각화만 만들기

```text
$alter-learning-studio
주제: CPU 사용률 기반 HPA와 Service 분산
대상: 처음 배우는 개발자
무엇이 '제어'이고 무엇이 '실제 요청 처리'인지 명확하게 구분해줘.
설명용 JSON과 실제 작동하는 HTML을 생성하고,
플레이/일시정지/타임라인/속도/슬라이더/퀴즈를 브라우저에서 검증해줘.
```

## 4. 전혀 다른 영역 학습하기

```text
$alter-learning-studio
주제: 영어 자동사·타동사와 전치사 관계
목표: comply with처럼 전치사가 필요한 이유를 예제로 판단하기
그림은 네트워크 다이어그램 대신 문장 구조 카드와 정답 확인을 활용해줘.
한 장면마다 예문이 바뀌는 인터랙티브 HTML로 만들고 결과를 검증해줘.
```

## 5. 여러 에이전트로 조사 + 구현 + 검증

```text
$alter-learning-studio
학습 주제: 벡터 검색과 RAG의 차이
코디네이터 1명이 학습 목표, 가정, 원본 JSON 및 품질 게이트를 소유해줘.
독립 에이전트가 가능하면 공식 자료 검증, 교육적 문제 설계,
스토리보드/모션, HTML 구현, 결과 감사를 나눠 처리해줘.
모든 조사 결과를 통합해 브라우저 동작과 설명의 정확성을 검증해줘.
실제로 수행하지 않은 테스트를 성공했다고 보고하지 마.
```

## 6. 모션그래픽 영상까지 필요할 때

```text
$alter-learning-studio
방금 만든 HTML 학습 내용을 9:16 설명 영상으로 제작하고 싶어.
장면별 컷/자막/내레이션/전환 타임라인을 먼저 작성하고,
접근 가능한 렌더링 도구가 있다면 실제 영상으로 렌더링 및 검증해줘.
렌더링 도구가 없다면 작동하는 HTML과 스토리보드까지만 전달하고
MP4 파일을 만들었다고 말하지 마.
```


## 토스 분위기 + 실제 모션그래픽 필수 (기본 프롬프트)

```text
$alter-learning-studio
주제: [학습할 개념]
A.L.T.E.R. 방식으로 학습하고 싶어.
기본 HTML은 토스와 유사한 밝고 미니멀한 분위기를 사용하되
공식 토스 에셋이나 디자인 코드는 복사하지 마.
시각화는 단순한 플로우차트나 카드 애니메이션이 아니라
원인 → 변화 → 전달 → 결과가 실제로 움직이는 모션그래픽으로 만들어줘.
장면 내 4비트 구성, 재생/일시정지/스크럽/속도 변경,
내 입력값에 반응하는 실험을 포함하고, 모바일에서도 검증해줘.
학습자가 설명할 수 있도록 진단 → 예측 → 실험 → 피드백을 진행해줘.
```

- OpenAI build skills documentation — https://learn.chatgpt.com/docs/build-skills (Codex detection, repository/global install)

- MDN prefers-reduced-motion — https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion
- Kubernetes Service / traffic — https://kubernetes.io/docs/concepts/services-networking/service/
- Kubernetes EndpointSlices — https://kubernetes.io/docs/concepts/services-networking/endpoint-slices/
- Kubernetes Horizontal Pod Autoscaling — https://kubernetes.io/docs/tasks/run-application/horizontal-pod-autoscale/

For new lessons, the agent should identify 3–4 primary subject-specific resources rather than reusing these implementation references as learning sources.
